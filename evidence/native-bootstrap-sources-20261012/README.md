# Checked bootstrap source dispatch evidence

All original source receipts and bytes are preserved. Four large JSON command /
source manifests are stored as deterministic gzip streams. `compression.json`
maps original filenames and SHA256 hashes to stored files; decompress before
checking `summary.json`'s original `evidence_sha256` entries. Original plaintext
versions also remain in the local source history and original qualification
workspace. No executable source or test result was changed by compression.

The tests and target probes qualify the bounded checked source dispatcher.
Production feature selection, temporary-unavailable UI behavior, real first-SD
capacity and startup entropy, final product composition and hardware remain
separate gates.
